# Basic-Chatbot-Python
A simple rule-based chatbot built with Python that responds to predefined user messages using functions, if-elif statements, loops, and basic input/output.

## Features

* Responds to greetings
* Answers basic questions
* Provides predefined responses
* Handles unknown messages
* Continuous conversation using a loop
* Exits when the user types `bye`

## Supported Messages

* hello
* hi
* how are you
* what is your name
* what can you do
* thanks
* thank you
* bye

## Technologies Used

* Python
* Functions
* If-elif statements
* While loop
* User input and output
* String handling

## How to Run

Run the following command:

```bash
python chatbot.py
```

Then enter messages in the console and interact with the chatbot.

## Example

```text
You: hello
Chatbot: Hi!

You: how are you
Chatbot: I'm fine, thanks!

You: what is your name
Chatbot: I'm a simple Python chatbot.

You: bye
Chatbot: Goodbye!
```

This project was created as part of a Python programming task to practice functions, conditional statements, loops, and user input/output.
